# Код к работе «Предсказание выживания пассажиров Титаника»

Реализация по `Titanik.docx`. CSV на 891 пассажира скопирован из локального
`Telegram Desktop/titanic.csv`; интернет для обучения не требуется.

## Jupyter Notebook

`Titanic.ipynb` содержит весь код по шагам с короткими комментариями.
Откройте его в Jupyter, VS Code или PyCharm и выполните все ячейки сверху вниз.
Файл `titanic.csv` должен лежать рядом. Сохранённые выводы показывают реальный
запуск на CPU. Файл `titanic_nn.py` для запуска ноутбука не требуется.

## Запуск

Из корня проекта с уже настроенным окружением:

```sh
.venv/bin/python titanic/titanic_nn.py
```

В отдельной папке или на другом компьютере сначала установите зависимости:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r titanic/requirements.txt
.venv/bin/python titanic/titanic_nn.py
```

Для Windows вместо `.venv/bin/python` используйте `.venv\Scripts\python.exe`.

Прогноз для двух пассажиров из работы без повторного обучения:

```sh
.venv/bin/python titanic/titanic_nn.py --predict titanic/examples.csv
```

Для другого CSV:

```sh
.venv/bin/python titanic/titanic_nn.py --predict /path/to/test.csv --predictions titanic/predictions.csv
```

Входные столбцы: `Pclass, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, Embarked`.
`PassengerId` необязателен, при наличии сохраняется в результате.
Для обучения дополнительно нужен `Survived` со значениями 0 и 1.
Поддерживаются разделители `,` и `;`. Пустые `Age` и `Fare` заполняются
средними обучающей выборки; неизвестные категории получают код −1.

## Что реализовано

- Стратифицированное разделение 70/20/10: 623 обучающих, 178 валидационных
  и 90 тестовых записей, seed 42.
- 11 признаков в порядке из работы: `Pclass, Sex, Age, SibSp, Parch,
  FamilySize, IsAlone, Ticket, Fare, Cabin, Embarked`.
- Извлечение буквенного префикса билета (`REG`, если букв нет) и палубы
  из каюты (`UNK`, если каюта неизвестна), кодирование категорий.
- `FamilySize = SibSp + Parch + 1`, `IsAlone = (FamilySize == 1)`.
- Стандартизация `Age` и `Fare`. Все параметры предобработки вычисляются
  только по обучающей части и сохраняются для новых пассажиров.
- PyTorch MLP: `11 → 16 → ReLU → 8 → ReLU → 1`.
  Выход — логит; sigmoid применяется при предсказании.
  [BCEWithLogitsLoss](https://docs.pytorch.org/docs/stable/generated/torch.nn.BCEWithLogitsLoss.html)
  уже включает sigmoid при вычислении потерь.
- Adam, learning rate 0.001, batch size 32, максимум 200 эпох.
  Early stopping: patience 10, min_delta 0.0001, восстановление лучших весов.
- Автоматический выбор CUDA при наличии, иначе CPU.
- Accuracy, precision, recall и F1 на отложенной тестовой части.

Другая обучающая выборка и предел эпох задаются через `--csv` и `--epochs`.
Папку результатов можно изменить через `--output-dir`.

## Фактический результат проверки

На CPU с seed 42 обучение остановилось на эпохе 50; восстановлены веса
эпохи 40. Валидационная потеря лучшей модели — около 0.4400.

| Метрика на 90 тестовых пассажирах | Значение |
| --- | ---: |
| Accuracy | 0.7667 |
| Precision | 0.7059 |
| Recall | 0.6857 |
| F1 | 0.6957 |

Вероятности для примеров: мужчина 25 лет из третьего класса — 0.0942;
женщина 30 лет из первого класса — 0.9155. Стоимость билетов в примерах
зафиксирована в `examples.csv`: в документе точные суммы не указаны.

Цифры 0.8333 и 0.7619 из документа не гарантируются: в нём нет исходных
индексов разбиения, весов и всех параметров исходного эксперимента.
Здесь приведён фактически выполненный запуск; тестовая часть не используется
для ранней остановки или подбора параметров. Результаты могут отличаться
между версиями библиотек и устройствами.

## Сохранённые файлы

Папка `artifacts/` содержит:

- `model.pt` — веса лучшей модели;
- `preprocess.pkl` — параметры предобработки;
- `history.csv` — потери и валидационная точность по эпохам;
- `metrics.json` — итоговые метрики и размеры выборок;
- `test_predictions.csv` — прогнозы и истинные классы тестовых пассажиров;
- `examples_predictions.csv` — прогнозы для двух примеров.

При повторном обучении файлы в выбранной папке результатов перезаписываются.
Загружайте `preprocess.pkl` только из доверенного источника: формат pickle
позволяет выполнять код при чтении. Приложенный файл создаётся самим скриптом.

## Проверки

```sh
.venv/bin/python -m unittest discover -s titanic -p 'test_*.py' -v
```

Тесты проверяют пропуски, новые категории, постоянные значения, ошибочные
данные, непересекающиеся выборки, расчёт статистик только по train,
восстановление лучших весов и совпадение прогнозов после загрузки модели.
